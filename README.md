Our project makes a KGNN-RAG for the MovieLens 1M ratings dataset with user 
The MovieLens dataset is a common dataset used in benchmarks, so it is a solid choice to compare against.

# Instructions
Download and run the Jupyiter Notebook. It will give you an API.
Run the API by copying the link to a new tab, input the password. 
Run HTML file, attached in the Code directory, and connect the API to it, That simple :)
The CSV files used in this project are in the Data directory, users.csv, rating.csv, and movies.csv from the MovieLens 1M ratings dataset.
The evaluation code is in the Evaluation directory, instructions on how to run are detailed in that.
